This project is only for running games you own on PC. Do not distribute pirated games. Please support official releases.
本项目仅限在 PC 上运行自己拥有的游戏，不支持任何盗版传播行为。请支持正版。

Open AegisLauncher.exe, select your own supported CUSA18093 game directory, configure options and start.
The Game language option selects Simplified or Traditional Chinese text; restart the game to apply it. The directory must contain all six CPKs.
The Import PKG tab accepts supported, already-decryptable packages; no retail decryption or update merging.
Enter/F confirms, Space/Backspace cancels, WASD moves, arrows select, Esc opens the menu.
Alt+Enter toggles fullscreen; F10 toggles statistics. Game logic remains 60 Hz.
The gamepad tab offers PC-added rumble on protagonist mech HP loss in battle (enabled by default).
Enemies, summons and other friendly objects do not trigger it. Save and restart to apply changes.
Settings and saves are stored in user/. Back it up before changing installations.
Rumble diagnostics: use the launcher's gamepad rumble test or F8 in-game to test both motors.
Include logs/controller-*.log and logs/<run>/stdout.log in reports, and whether each test vibrated.
Logs record SDL version/DLL path, devices, guest requests and SDL results. SDL acceptance does not confirm physical vibration.
